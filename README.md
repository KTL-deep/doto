# Doto — Полноценный аналог TickTick (Productivity Hub)

**Doto** — современный, быстрый и многофункциональный веб-сервис для управления задачами, привычками, временем и продуктивностью в стиле TickTick.

---

## 🌟 Ключевые возможности

1. **Менеджер задач и списков (GTD)**:
   - Умные смарт-папки: *Входящие (Inbox)*, *Сегодня (Today)*, *Следующие 7 дней (Next 7 Days)*, *Архив*, *Корзина*.
   - Пользовательские списки и папки с кастомными цветами и иконками.
   - Теги (#срочно, #идея, #баг) с цветовой маркировкой.
   - Приоритеты задач: Высокий (Красный), Средний (Желтый), Низкий (Синий), Без приоритета.
   - Умный быстрый ввод (Natural Language Parsing):
     - `^сегодня`, `^завтра`, `^2026-08-25` — установка даты
     - `!1`, `!2`, `!3` или `!!!` — установка приоритета
     - `#работа`, `#личное` — теги
     - `*daily`, `*weekly`, `*weekdays` — повторение задачи
   - Повторяющиеся задачи (RRULE: Ежедневно, По будням, Еженедельно, Ежемесячно).
   - Подзадачи и чеклисты с подсчетом прогресса (`2/5`).
   - Markdown-заметки и подробные описания к каждой задаче.
   - Закрепление (Pin) важных задач наверху.

2. **Матрица Эйзенхауэра (Eisenhower Matrix)**:
   - 4 квадранта: *Q1: Срочно и Важно*, *Q2: Не срочно, но Важно*, *Q3: Срочно, но Не важно*, *Q4: Не срочно и Не важно*.
   - Быстрое перетаскивание и распределение приоритетов.

3. **Канбан-доска (Kanban View)**:
   - Переключение любого списка в режим канбан-колонок (*К выполнению*, *В процессе*, *Готово*).

4. **Интерактивный календарь (Calendar View)**:
   - Месячная сетка с распределением задач по дням и цветовой индикацией приоритетов.

5. **Трекер привычек (Habit Tracker)**:
   - Ежедневные привычки с круговыми чек-ин кнопками за последние 7 дней.
   - Подсчет непрерывной серии дней (🔥 Streak) и личных рекордов.
   - Выбор эмодзи-иконок и целевой частоты.

6. **Фокус & Таймер Помодоро (Pomodoro Timer)**:
   - Режимы: Сессия фокуса (25м), Короткий перерыв (5м), Длинный перерыв (15м).
   - Привязка сессий таймера к конкретным задачам.
   - **Встроенный генератор фоновых звуков (Ambient Noise Generator)** через Web Audio API (Звук дождя 🌧️, Белый шум 📻, Глубокий фокус 🌊) — работает 100% автономно без внешних аудио-файлов!
   - Звуковые эффекты завершения сессий и выполнения задач.

7. **Статистика и Геймификация (Productivity Karma)**:
   - Подсчет очков Кармы и уровней продуктивности (*Начинающий* -> *Продвинутый* -> *Мастер* -> *Дзен-Мастер*).
   - График выполнения задач за последние 7 дней.
   - Процент эффективности и общее время в фокусе.

8. **Премиальный дизайн и темы**:
   - Темы оформления: *Dark Carbon Pro*, *Pure Light*, *Sunset Glow*, *Deep Forest*, *Cyber Slate*.
   - Адаптивный интерфейс, плавные анимации и горячие клавиши (`Ctrl+K`, `/`, `Esc`).

## 🛠️ Архитектура и стек технологий

### Бэкенд (Backend)
- **Язык**: Python 3.11+
- **Фреймворк**: FastAPI (асинхронный, высокая производительность, автодокументация OpenAPI/Swagger)
- **База данных**: SQLite (с поддержкой Async SQLAlchemy + `aiosqlite`)
- **Безопасность**: JWT (Access Tokens), хеширование паролей через `bcrypt`
- **Валидация**: Pydantic v2

### Фронтенд (Frontend)
- **Структура**: Чистый семантический HTML5
- **Стилизация**: Модульный Vanilla CSS с дизайн-токенами, темами и адаптивной версткой
- **Логика**: Модульный Vanilla JavaScript (ES6 Modules, реактивный Store, Web Audio API)

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
python -m venv .venv
# Для Windows:
.\.venv\Scripts\activate
# Для Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск приложения (Бэкенд + Фронтенд)
```bash
python run.py
```

Приложение будет доступно по адресу:
- 🌐 **Веб-приложение**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- 📚 **Интерактивная API документация (Swagger UI)**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- 📖 **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

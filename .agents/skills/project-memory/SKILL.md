# Project Memory Management Skill

Этот скил предназначен для создания, чтения и постоянной актуализации файла `PROJECT_MEMORY.md` в корне проекта.

---

## 🎯 Цели и принципы работы

1. **Экономия токенов и времени**: При старте новой сессии агент считывает только `PROJECT_MEMORY.md` вместо сканирования всей файловой системы через `list_dir` и `grep_search`.
2. **Непрерывность контекста**: В файле фиксируются архитектура, стек, реализованные эндпоинты, модели БД, текущее состояние и следующие шаги.
3. **Автообновление**: После каждого значимого шага или ответа агент обновляет `PROJECT_MEMORY.md`, сохраняя актуальный срез проекта.

---

## 🔄 Протокол работы агента (Workflow)

### Шаг 1: Старт новой сессии / Запуск проекта
1. Проверить наличие `PROJECT_MEMORY.md` в корне проекта.
2. Если файл **существует**:
   - Прочитать его через `view_file`.
   - Использовать извлеченный контекст для мгновенного ответа пользователю без лишнего рекурсивного чтения всех папок.
3. Если файл **отсутствует**:
   - Создать `PROJECT_MEMORY.md` через `write_to_file`.
   - Заполнить его актуальной информацией о структуре, стеке и статусе проекта.

### Шаг 2: Внесение изменений в код
1. Выполнить поставленные пользователем задачи по разработке.
2. Проверить работоспособность кода/тестов.

### Шаг 3: Обновление `PROJECT_MEMORY.md` перед завершением ответа
1. Отредактировать `PROJECT_MEMORY.md` (через `replace_file_content` или `write_to_file`):
   - Обновить дату и статус.
   - Отметить выполненные пункты в секции «Выполненные задачи».
   - Добавить новые созданные файлы, модели, эндпоинты.
   - Актуализировать секцию «План на следующие шаги».
